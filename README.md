# 🌤️ Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript. It fetches real-time weather data from a public API and displays it in a clean UI.

## 🔍 Features
- Search weather by city name
- Displays:
  - Temperature
  - Weather conditions (e.g., cloudy, sunny)
  - Humidity
  - Wind speed
- Dynamic icons based on weather
- Error handling for invalid city names
- Clean and responsive UI design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- OpenWeatherMap API
